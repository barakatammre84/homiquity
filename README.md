# Homiquity

Automated loan operations from application through funding, with an accountable loan officer
involved and assisted throughout.

Start with [AGENTS.md](AGENTS.md), [product direction](CTO_ROADMAP.md), and
[current implementation context](knowledge-base/ACTIVE_CONTEXT.md).
The [knowledge index](knowledge-base/README.md) locates technical references and primary sources.

For local setup use [LOCAL_DEV.md](knowledge-base/runbooks/LOCAL_DEV.md).
The application uses the existing React/TypeScript client and Node server; inspect the code and
package scripts for current implementation details. Do not treat a demo as a live loan service.
